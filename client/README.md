# SpendSmart frontend

This is the React/Vite client for SpendSmart. It contains the dashboard,
transaction manager, category budgets, reports, and custom categories.

## Start the client

```sh
npm install
npm run dev
```

The frontend expects the API at `http://localhost:5000/api` by default. Override
it with `VITE_API_URL` in `.env.local`.

See the [project README](../README.md) for full-stack setup, API details, and a
suggested class presentation walkthrough.
